# Heavy Equipment Price Prediction

## Project Overview

This project predicts the selling price of heavy equipment using
machine learning techniques.

## Problem Statement

The objective is to predict the selling price of heavy equipment
from historical equipment characteristics.

## Dataset

The dataset contains numerical and categorical information about
heavy equipment.

## Approach

1. Exploratory Data Analysis
2. Missing Value Analysis
3. Data Preprocessing
4. Categorical Encoding
5. Feature Engineering
6. Target Encoding
7. Target Transformation
8. Model Training
9. Cross-Validation
10. Hyperparameter Tuning
11. Model Evaluation

## Models Used

- Ridge Regression
- LightGBM
- CatBoost

## Feature Engineering

Important information such as horsepower and machine weight was
extracted from textual specifications.

## Evaluation Metric

RMSE (Root Mean Squared Error)
